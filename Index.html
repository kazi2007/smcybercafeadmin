Firestore Security Rules (রেফারেন্স)

পুরোনো Rules পুরোটা মুছে ফেলবেন না। বিদ্যমান collection rules বজায় রেখে printOrders ও fileChunks-এর match block-টি যোগ করুন। নিচের কোডটি রেফারেন্স।

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /services/{id} { allow read: if true; allow write: if request.auth != null; }
    match /ads/{id} { allow read: if true; allow write: if request.auth != null; }
    match /bookings/{id} { allow create: if true; allow read, update, delete: if request.auth != null; }
    match /tracking/{id} { allow create: if true; allow read: if true; allow update, delete: if request.auth != null; }
    match /settings/{id} { allow read: if true; allow write: if request.auth != null; }
    match /printOrders/{orderId} {
      allow create: if true;
      allow read, update, delete: if request.auth != null;
      match /fileChunks/{chunkId} {
        allow create: if request.resource.data.data is string
          && request.resource.data.data.size() <= 700000;
        allow read, delete: if request.auth != null;
      }
    }
  }
}

অ্যাডমিন ইউজার তৈরি

Firebase Console > Authentication > Sign-in method > Email/Password চালু করুন, তারপর Users ট্যাব থেকে "Add user" দিয়ে অ্যাডমিনের ইমেইল ও পাসওয়ার্ড যুক্ত করুন। যতজন স্টাফকে অ্যাক্সেস দিতে চান তত ইউজার তৈরি করতে পারেন।

নিরাপত্তা ও ফাইল আপলোড নোট

এই HTML ফাইলগুলো Firebase-এর সঙ্গে সংযুক্ত। Phone+password login এখানে Firebase Auth-এর email/password provider-এ phone alias ব্যবহার করে। প্রকৃত Admin password reset, role-based access, নিরাপদ stock reservation, Coin FIFO/expiry, coupon validation এবং payment verification production-এ enforce করতে Firebase Cloud Functions/secure rules প্রয়োজন। User collection-এ password কখনও রাখবেন না। Print file Firestore-এর ছোট chunk document-এ থাকবে; Firebase Storage লাগবে না।
